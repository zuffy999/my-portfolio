# zuffy999 — Frontend Developer Portfolio

Особисте портфоліо розробника **zuffy999**, створене для презентації навичок, технологій та власних проєктів.

## Про мене

Я початківець у сфері Frontend Development. Цікавлюся веброзробкою, програмуванням та створенням цифрових продуктів.

Моя мета — розвивати навички програмування та створювати сучасні й функціональні вебсайти.

## Розділи сайту

- **Home** — головна сторінка та коротке представлення.
- **About Me** — інформація про мене та мої цілі.
- **Tech Stack** — технології та інструменти.
- **Projects** — мої проєкти.
- **Contact** — посилання для зв'язку.
